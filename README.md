## 🚀 Featured Projects

### 🧠 [MemoryOS](https://github.com/PulkitChugh21/MemoryOS)

**Persistent AI Memory System · FastAPI · React · Supabase · Qdrant · Gemini**

An AI workspace designed to give assistants **persistent long-term memory** instead of treating every conversation as an isolated session.

* Combines **episodic and semantic memory** to preserve context across conversations
* Uses **Qdrant vector search** for semantic memory retrieval
* Uses **Gemini** for LLM responses and embeddings
* Built a modular architecture with **React + TypeScript frontend** and **FastAPI backend**
* Includes authentication, project management, and user/project memory isolation
* Designed with a roadmap toward **self-healing memory, multimodal ingestion, enterprise scale, and external integrations**

> **Focus:** LLM Applications · AI Memory · RAG · Vector Search · Backend Architecture
